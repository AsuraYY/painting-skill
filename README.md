# painting-skill

汇报级图绘制技能（skill 名称：**arch-diagram**）——为 PPT 汇报绘制精美、可编辑的图：流程图、架构图、系统架构、泳道图、数据流图、状态机、拓扑图、汇报图、PPT 配图。

## 特点

- **规则驱动，不套模板**：固定的是规则（画布解剖、连线语义、字号阶梯、自检清单），留白的是参数（色板、尺寸每次按内容与主题运行时推导）。
- **三阶段确认硬流程**：① 结构说明（先推荐说明格式 → 按选定格式产出说明）→ 用户确认 → ② 块表 + 边表（固定数据表结构，边表含线型/头与单双向列）→ 用户确认 → ③ 作图；禁止跳阶段、禁止合并阶段一次出图。
- **科研感来自纪律**：白底、单主色相 + ≤2 语义辅色、语义-线型-头型三者锁死、图例完整、交付前逐条自检。
- **可二次编辑**：以 drawio 结构化 XML 为主通道，图层 / 组按语义命名，连线绑定锚点，双击即可改图。

## 输出通道

| 优先级 | 格式 | 说明 |
|---|---|---|
| 主通道 | drawio | 结构化 XML，图层 / 组语义命名，连线绑锚点，可编辑 |
| 备选 | PPT | 优先原生形状（可编辑），退化时整图导出单页 SVG / PNG |
| 第三 | SVG | 单页矢量 |

## 安装与使用

将本仓库克隆（或仅复制 `SKILL.md`）到技能目录即可：

- 用户级：`~/.workbuddy/skills/arch-diagram/SKILL.md`
- 项目级：`<workspace>/.workbuddy/skills/arch-diagram/SKILL.md`

之后对话中提出画图 / 绘制 / 画流程图 / 架构图 / 数据流图 / 泳道图 / 状态机 / 拓扑图 / PPT 配图，或明确要 drawio 时自动触发。

## 版本记录

### v3（当前版本）

相对 v2 的主要迭代：

- **需求解析协议 → 三阶段确认协议（硬流程，先表后图）**：任何一次作图必须走完 ①结构说明 → ②块表+边表 → ③作图 三个阶段，每阶段产出交用户确认、拿到明确同意后才进下一阶段；禁止跳阶段、禁止合并阶段一次出图。
- **阶段一 · 结构说明**：文本/文档输入先解析流程结构，走「先推荐、后选择、再成文」——推荐一种说明格式并交代理由；候选含内置**格式 A 单段式整体架构说明**（图题开篇 / 分区逐条 / 流向句 / 收尾三项 / 输出格式）与**格式 B 四段式层级说明**（图类与分层 / 各层模块 / 连线规则 / 风格基调），A/B 不合适时必须**自拟格式 C** 并给出段落结构骨架；同阶段集中补齐结构 / 连线语义 / 用途气质 / 色调 4 个待问项。
- **阶段二 · 块表 + 边表**：固定数据表结构；块表（模块名 / 所属层 / 图标类别 / 块级 / 说明），边表（起点 / 终点 / 语义 / **线型+头型成对填写** / **单双向必填** / 走线备注）；行数与图中模块、连线一一对应，语义禁填「关联」类无信息词。
- **阶段三 · 作图**：两表确认后按规则作图，图与确认后的表逐行对应；画图期间用户改表须回到对应阶段重新确认。
- **改图边界**：纯点名式小改走第 11 节改图协议；凡涉及结构变动（加减层、增删模块/连线、换风格）必须先回到阶段一或二重新确认。
- **DoD 新增**：交付自检清单增加「三阶段确认齐全」检查项。
- frontmatter `description` 同步更新为三阶段确认流程描述。

### v2

相对 v1 的主要迭代：

- 新增**规则冲突裁决顺序**：信息密度 > 用户偏好 > 语义正确 > 版式美观 > 字面合规，字面合规但画面变差时选画面。
- **图例瘦身**：图例 ≤6 行、每项 ≤12 字，禁止写成说明文；图例声明的形状语义必须与实际一一对应。
- **干线锚点语义化**（替代「同级干线必须同轴」）：干线两端锚定语义模块侧边中点，禁止悬空接缝、禁止斜线。
- 新增 **5b 块间箭头锚点与流转完整性**：主流程连线必须完整、一律实线直连，禁止虚线画主流程、禁止长虚线绕行。
- 新增 **7e 单图规模上限与拆图**：名词 >40 / 分区 >6 等阈值触发才拆，拆 = 完整主图 + 分图同批交付，禁止掏空主图冒充总览。
- **风格冻结**（改图 / 迭代模式）：色板、字号、图标、布局骨架沿用上一版，未点名区域零改动；「参数现推」仅限全新图。
- **投影模拟自检**：缩 50% 层级可辨、3 米外模块名可读；扩充交付自检清单（26 项）。
- 同类元素符号全图统一、清单条带推荐「·」中性符号、反模式清单大幅扩充。

### v1

初始版本：需求解析协议、图类路由、画布解剖、元素字典、连线语义字典、色彩系统、字号阶梯、drawio 输出约束、反模式清单、交付自检清单、改图协议。
